跨平台

Windows x64/ARM64、macOS Intel/Apple Silicon；悬浮球、收藏、历史、12 语言。

技术架构

Electron 跨平台

支持 Windows（x64 / ARM64）与 macOS（Intel / Apple Silicon），多进程架构保障稳定性。

Vue 3 前端

桌面端 Element Plus + 移动端 Vant，Pinia 状态管理。

SQLite + sqlite-vec

本地存储设置、历史与文本/画面向量，支撑语义搜索与找相似。

AI 集成

可配置分析与向量化服务；保留 ONNX 本地美学评分（Legacy 可选）。

Electron IPC

桌面端主进程与渲染进程之间的安全通信。

HTTP REST + SSE

H5 服务提供 REST 接口与 Server-Sent Events 推送（如设置同步），已不使用 Socket.IO。

插件化系统

扩展壁纸源与能力，无需重新编译核心应用。
