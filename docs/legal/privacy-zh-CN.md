# 飞鸟壁纸 隐私政策

> **适用版本**：2.0.0 及以上  
> **最后更新**：2026-06-10  
> **联系邮箱**：zmn2007.hi@163.com

飞鸟壁纸（Flying Bird Wallpaper，以下简称「本应用」）由 OXOYO 开发。我们重视你的隐私。本政策说明本应用如何处理与你的使用相关的信息。

---

## 1. 总体原则

- 本应用**不提供用户账号体系**，默认**不向开发者服务器上传**你的壁纸文件、浏览记录或 AI 分析内容。
- 绝大多数数据保存在**你的本机**（应用数据目录与本地数据库）。
- 仅在下列**你主动启用或触发**的场景下，才可能发生网络通信；通信对象由功能决定，而非默认后台上报。

---

## 2. 本地存储的数据

本应用可能在本地保存（包括但不限于）：

| 类型 | 说明 |
|------|------|
| 壁纸资源元数据 | 本地扫描、下载、插件导入的文件路径、标题、标签、评分等 |
| 使用记录 | 收藏、历史、隐私空间、合集、统计数据 |
| 应用设置 | 主题、壁纸类型、律动/动态参数、AI 配置等 |
| AI 分析结果 | 标签、描述、NSFW 等级、向量嵌入等（在本地生成或拉取后写入本地库） |
| 隐私空间密码 | 以加盐哈希形式保存在本机数据库，**明文不会上传** |
| API Key 等凭据 | 由你在设置中填写，保存在本机，请求时发往对应服务商 |

上述数据主要用于在本设备上提供浏览、搜索、设壁纸、AI 整理等功能。

---

## 3. 可能发生的网络通信

### 3.1 检查更新

在**正式安装版**中，应用启动后可能自动、或在菜单中手动检查更新，并访问 **GitHub Release** 等发布渠道获取版本号与安装包信息，**不包含**你的壁纸或个人文件。开发版（未打包）行为可能不同。

### 3.2 插件与远程壁纸源

安装插件、浏览插件市场、从远程源下载壁纸时，应用会访问**你配置或选择的第三方 URL**（例如 GitHub 上的插件清单与资源包）。这些服务由第三方运营，其隐私实践不受本政策约束，请自行阅读相应说明。

### 3.3 网页壁纸（可选）

若你设置**网页壁纸**并填写外部 URL，应用会在桌面层加载该网页，由对应网站按其政策处理访问数据。

### 3.4 AI 功能（可选）

在 **设置 → AI** 中启用 AI 并配置**非本机**服务（如 OpenAI、DeepSeek、OpenRouter 等）时：

- 为完成分析，本应用可能将**本地图片或视频帧经压缩后**发送至你所选的服务商；
- API Key、请求地址由你在本机填写，请求直接发往对应服务商；部分服务商可能同时收到 Referer、应用名称等请求元数据（若你在设置中填写）；
- 使用**本机 Ollama / localhost 兼容端点**时，数据通常不离开你的设备；
- 使用**内置视觉向量模型**（如 MobileCLIP）时，推理在本机完成；模型文件随安装包或构建脚本提供，不因此上传你的壁纸。

请在启用云端 AI 前确认你信任该服务商及其隐私政策。

### 3.5 H5 局域网服务（可选）

开启 **H5 服务** 后，本机会在局域网内提供网页浏览与部分 API（如搜索、收藏、设置同步等），同网段设备可通过二维码等方式访问，**默认无独立账号登录**（隐私空间相关操作仍可能要求本机已设置的隐私密码）。**请勿在不可信公共网络中开启**。

---

## 4. 我们不会默认做的事

- 不收集姓名、手机号等注册信息（无账号体系）；
- 不默认接入第三方广告或行为分析 SDK（以当前开源版本为准）；
- 不默认将你的壁纸库上传至开发者服务器。

> 若你自行 fork 或修改构建版本并接入统计/云同步，以该版本实际行为为准。

---

## 5. 隐私空间

- **隐私空间**：通过本地密码保护部分收藏，逻辑与数据均在本地完成。

上述功能**不能替代**你对本地文件的管理责任。

---

## 6. 数据的删除与导出

- 可在应用内执行「清空资源库」等操作，删除本地记录（是否删除磁盘文件取决于具体操作说明）；
- 卸载应用后，操作系统通常会移除对应应用数据目录；
- 本应用当前**不提供**一键导出全部个人数据的专用功能；重要文件请自行备份。

---

## 7. 未成年人

本应用不面向刻意收集未成年人个人信息。若监护人发现未成年人误用云端 AI 或局域网功能，请关闭相关选项并妥善管理设备。
