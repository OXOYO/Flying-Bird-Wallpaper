Technology Architecture

Electron Cross-platform

Windows (x64 / ARM64) and macOS (Intel / Apple Silicon) with a multi-process architecture for stability.

Vue 3 Frontend

Modern desktop UI (Element Plus) and mobile H5 UI (Vant) with Pinia state management.

SQLite + sqlite-vec

Local data, settings, history, text/visual vectors for semantic search and similarity.

AI Integration

Configurable providers for analysis and embeddings; optional ONNX legacy aesthetic scoring.

Electron IPC

Secure communication between the main process and renderer windows on desktop.

HTTP REST + SSE

H5 server exposes REST endpoints and Server-Sent Events (e.g. settings sync) — no Socket.IO.

Plugin System

Extend wallpaper sources and capabilities without rebuilding the core app.
